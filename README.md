# React Native Day 9 — Аватар профілю з локальним збереженням

Домашнє завдання: Expo-застосунок, що дозволяє обрати фото з галереї або зробити його камерою, оптимізувати (ресайз + стиснення) та зберегти локально, щоб аватар залишався після перезапуску застосунку.



## Технології

- Expo SDK 57, React Native 0.86, TypeScript
- `expo-router`, `expo-image-picker`, `expo-image-manipulator`, `expo-file-system`

## Структура

```text
├── app/
│   ├── _layout.tsx              # Кореневий Stack
│   └── index.tsx                # Екран профілю (готова верстка)
├── src/
│   ├── services/
│   │   └── mediaService.ts      # Оптимізація та робота з файловою системою
│   └── hooks/
│       └── useProfilePhoto.ts   # Дозволи, вибір/зйомка фото, стан
├── app.json                     # Плагін expo-image-picker з текстами дозволів
└── package.json
```

## Запуск

```bash
npm install
npx expo start
```

Відскануйте QR-код у **Expo Go** (версія з підтримкою SDK 57). Для тестування камери використовуйте фізичний смартфон.

## Примітка щодо `expo-file-system`

Починаючи з Expo SDK 54, класичний API (`documentDirectory`, `getInfoAsync`, `copyAsync`, `deleteAsync`) перенесено в окремий entry point, тому в сервісі використовується імпорт:

```ts
import * as FileSystem from 'expo-file-system/legacy';
```

## Як перевірити

1. Натиснути «Галерея» або «Камера», надати дозвіл, обрати/зробити фото та обрізати його.
2. Повністю закрити застосунок і відкрити знову — аватар має залишитися.
3. Натиснути «Видалити фото» — має з'явитися плейсхолдер.
4. Відхилити дозвіл — має з'явитися діалог з кнопкою «Відкрити налаштування».
